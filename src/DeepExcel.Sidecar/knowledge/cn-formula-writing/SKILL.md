# 中文用户的公式写入

在 WPS 里工作时，另外读 `load_skill("cn-formula-writing", "wps.md")`。

## 一、写法规则

- **函数名一律用英文**：`SUMIFS`、`VLOOKUP`。中文版 Excel 和 WPS 的函数名也是英文，写进去不会被翻译。
- **标点一律半角**：逗号 `,`、括号 `()`、引号 `""`、冒号 `:`。用户消息里的全角「，（）“”」如果照抄进公式，
  会得到 #NAME? 或直接写入失败。公式里的中文字符串本身可以是中文：`=IF(A2>0,"盈利","亏损")`。
- **工作表名带空格、中文括号或以数字开头时要加单引号**：`='2026年 预算'!B3`、`='1月'!C5`。
  纯中文、不含空格的表名（`销售明细!A1`）可以不加，加了也不会错——拿不准就加。
- 引用别的工作簿会让公式依赖那个文件的路径，除非用户要求，不要这么写。

## 二、版本兼容

中国用户里 Excel 2010 / 2013 / 2016 和 WPS 老版本都很常见。下面这些函数只有 Microsoft 365 或 Excel 2021 以后才有：

`XLOOKUP` `XMATCH` `FILTER` `SORT` `SORTBY` `UNIQUE` `SEQUENCE` `LET` `LAMBDA` `TEXTJOIN`（2019）`IFS` / `SWITCH` / `MAXIFS` / `MINIFS`（2019）`TEXTSPLIT` / `VSTACK` / `HSTACK`（更晚）

- 不知道用户的版本时，优先用到处都能用的写法：`INDEX` + `MATCH` 代替 `XLOOKUP`，`SUMIFS` / `COUNTIFS`，嵌套 `IF` 代替 `IFS`。
- 用户在工作簿里已经在用某个新函数，说明他的版本支持，可以跟着用。
- 动态数组函数（FILTER、UNIQUE、SORT）会溢出到下方和右侧：写之前确认溢出区域是空的，否则得到 #SPILL!。
- 老版本打开含动态数组的文件，会看到 `_xlfn.` 前缀或 #NAME?。

## 三、中文场景的常用写法

| 需求 | 写法 |
|---|---|
| 显示成万元（不改数值） | 数字格式 `0!.0000"万"`（固定四位小数）；要保留两位，用公式 `=ROUND(A2/10000,2)` 另起一列并在表头写「万元」 |
| 金额大写（壹佰贰拾叁元肆角伍分） | 数字格式 `[DBNum2]` 会把小数点原样显示成「壹佰贰拾叁.肆伍」，不符合票据写法；要用公式拼：整数部分 `TEXT(INT(A2),"[DBNum2]")&"元"`，角、分分别取位，没有角分时写「整」 |
| 中文小写数字（一百二十三） | 数字格式 `[DBNum1]` |
| 中文日期 | 数字格式 `yyyy"年"m"月"d"日"`；取星期：`=TEXT(A2,"aaaa")` 得到「星期四」 |
| 按月汇总 | `=SUMIFS(金额列, 日期列, ">="&DATE(2026,9,1), 日期列, "<"&DATE(2026,10,1))`——不要用 `MONTH()` 拼文本比较 |
| 同比 / 环比 | `=IF(上期=0,"",本期/上期-1)`，上期为 0 或负数时增长率没有意义，要说明 |
| 占比 | `=B2/SUM($B$2:$B$100)`，分母绝对引用 |

## 四、财务取整

- 金额结果套 `ROUND(x,2)`：浮点误差会让 0.1+0.2 显示正常但比较不相等，分项加总与合计差一分钱。
- 「显示两位小数」只是格式，不改变数值；报表勾稽要求相等时，用 ROUND 之后的值比较。
- 四舍五入用 `ROUND`；截断用 `ROUNDDOWN` 或 `TRUNC`；进一用 `ROUNDUP`。个税、社保等有明确规则的，按规则来。
- 比较两个金额是否一致：`=ABS(A2-B2)<0.005`，不要直接 `=A2=B2`。

## 五、查找返回 #N/A 的常见原因

1. 类型不一致：一边是文本「001」，一边是数字 1。`=ISTEXT(A2)` 两边各查一次。
2. 首尾空格、不间断空格 CHAR(160)、全角空格。
3. VLOOKUP 第四个参数省略了，变成近似匹配：精确查找必须写 `FALSE` 或 `0`。
4. 查找列不在区域的第一列（VLOOKUP 只能往右查）：改用 `INDEX` + `MATCH`。
5. 查找区域没有绝对引用，向下填充后错位：`$A$2:$C$500`。

想把 #N/A 显示成空：`IFERROR(...,"")` 会把所有错误都吞掉，包括引用写错了的；只想处理找不到时，用 `IFNA`（2013 及以后）。

## 六、写入之前想清楚

- 相对 / 绝对引用：向下填充时哪些要跟着动，哪些要固定。写完看最后一行的公式。
- 一整列用同一个公式，不要中间夹着手敲的值。
- 公式里写死的数字（税率 0.13、汇率 7.1）最好放进单独的单元格再引用，并告诉用户在哪里改。
- 公式很长时拆成辅助列，比一个巨长的嵌套 IF 更容易让用户看懂和核对。

## 常见报错

| 错误 | 常见原因 |
|---|---|
| #NAME? | 全角标点；函数名拼错；新函数在旧版本里不存在；文本没加引号 |
| #VALUE! | 文本参与了算术运算（文本型数字、带单位的金额「100元」） |
| #REF! | 引用的行列或工作表被删了 |
| #DIV/0! | 分母为 0 或空：`=IF(B2=0,"",A2/B2)` |
| #SPILL! | 动态数组的溢出区域被占用 |
| 公式显示为文本不计算 | 单元格格式是「文本」，或公式前面有空格 / 单引号：改成常规后重新写入 |
| 循环引用警告 | 合计公式把自己也算进去了（SUM 的范围包含了合计所在格） |
