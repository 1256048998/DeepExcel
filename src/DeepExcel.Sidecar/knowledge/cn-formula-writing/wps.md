# WPS 表格与 Excel 的公式差异

在 WPS 里工作时读（上下文里的 host 是 wps）。WPS 各版本差异很大，下面是写公式时需要当心的地方，
拿不准时写到处都能用的写法，写完回读计算结果确认。

## 函数可用性

- WPS 较新的版本支持 XLOOKUP、FILTER、UNIQUE、SORT 等动态数组函数，老版本（尤其是政企定制版）不支持。
  用户工作簿里没有出现过这些函数时，默认用 INDEX + MATCH、SUMIFS。
- WPS 有一些自己的函数（例如人民币大写、身份证相关的函数），在 Excel 里打开会变成 #NAME?。
  **不要写 WPS 独有函数**，除非用户明确说这个文件只在 WPS 里用。
- LAMBDA、LET 这类较新的函数在 WPS 里的支持程度不一，避免使用。

## 数组公式

- 老版本 WPS 的数组公式需要按 Ctrl+Shift+Enter 输入；通过接口写入时，普通公式里用到数组运算
  （如 `SUMPRODUCT` 以外的 `SUM(IF(...))`）可能只算第一个元素。优先用 SUMPRODUCT、SUMIFS 这类本身就接受数组的函数。
- 动态数组溢出（#SPILL!）的行为和 Excel 基本一致，但老版本不会溢出，只显示左上角一个值。

## 格式与显示

- `[DBNum1]` / `[DBNum2]` 中文数字格式在 WPS 里可用，显示效果和 Excel 略有差异，写完看一眼。
- 自定义数字格式里的中文字符串（`"万"`、`"元"`）两边都支持。

## 宏与脚本

- WPS 的宏是 JS 宏（JSA），不是 VBA；个人版通常没有 VBA 环境。需要批处理时用平台提供的执行工具，
  不要给用户一段 VBA 让他自己粘贴。
- 事件、对话框、打印设置这类依赖宿主对象模型的操作，两边差异最大，做之前先用只读工具确认对象存在。

## 文件格式

- .et 是 WPS 自己的格式；要在 Excel 里打开，提醒用户另存为 .xlsx。
- 含 WPS 独有函数的 .xlsx 在 Excel 里打开会出 #NAME?：交付前用 find 搜一下公式里有没有不认识的函数名。
