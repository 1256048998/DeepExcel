# 工资表与个税（居民个人工资薪金，累计预扣法）

工资表出错的代价是真金白银，而且涉及员工隐私。每一步都用公式、每个参数都放参数表，汇报时不要在回复里复述身份证号和具体工资。

## 一、参数不写死

以下这些**随城市、年份、单位变化**，一律放在单独的「参数」表里，公式引用参数表：

- 社保公积金缴费基数的上下限（每个城市每年调整）
- 个人缴费比例：常见为养老 8%、医疗 2%（部分城市另有大额医疗）、失业 0.2%–0.5%、公积金 5%–12%——**以用户提供的当地当年标准为准**，没有就问
- 专项附加扣除的金额：按员工申报的数额，从专项附加扣除表引用，不要按标准自己推算
- 减除费用（目前 5000 元/月）和税率表也放参数表，政策调整时只改一处

用户没给参数时，先列出需要的参数请用户确认，不要默认一个城市的标准。

## 二、累计预扣法

每月计算（第 n 个月，n 为本单位本年度任职月数）：

```
累计应纳税所得额 = 累计收入 − 累计免税收入 − 累计减除费用（5000 × n）
               − 累计专项扣除（三险一金个人部分）− 累计专项附加扣除 − 累计其他扣除
累计应纳税额   = 累计应纳税所得额 × 预扣率 − 速算扣除数
本月应预扣税额 = 累计应纳税额 − 累计减免税额 − 累计已预扣税额（小于 0 时本月为 0）
```

累计预扣率表（综合所得）：

| 累计应纳税所得额 | 预扣率 | 速算扣除数 |
|---|---|---|
| 不超过 36,000 | 3% | 0 |
| 36,000 – 144,000 | 10% | 2,520 |
| 144,000 – 300,000 | 20% | 16,920 |
| 300,000 – 420,000 | 25% | 31,920 |
| 420,000 – 660,000 | 30% | 52,920 |
| 660,000 – 960,000 | 35% | 85,920 |
| 超过 960,000 | 45% | 181,920 |

公式写法（A2 是累计应纳税所得额；税率表放参数表更好）：

```
=ROUND(MAX(A2*{0.03,0.1,0.2,0.25,0.3,0.35,0.45}-{0,2520,16920,31920,52920,85920,181920},0),2)
```

本月税额 `=MAX(0, ROUND(累计应纳税额 − 累计已预扣, 2))`。

- **累计列要跨月一致**：本月的「累计已预扣」必须等于上月的「累计应纳税额」口径下实际预扣的合计。
  拿到多个月的表时，逐月核对累计列是否衔接。
- 年中入职：n 从入职当月算起。当年首次取得工资薪金的员工，按现行规定可以从 1 月起累计减除费用——
  是否适用问用户（要看员工本年是否在别处取得过工资）。
- 离职、跨单位：累计只算本单位。

## 三、年终奖（全年一次性奖金）

可以选择单独计税（现行政策执行至 2027 年底，以最新政策为准）：奖金 ÷ 12 查**月度**税率表，
应纳税额 = 奖金 × 税率 − 速算扣除数。

| 月均额 | 税率 | 速算扣除数 |
|---|---|---|
| 不超过 3,000 | 3% | 0 |
| 3,000 – 12,000 | 10% | 210 |
| 12,000 – 25,000 | 20% | 1,410 |
| 25,000 – 35,000 | 25% | 2,660 |
| 35,000 – 55,000 | 30% | 4,410 |
| 55,000 – 80,000 | 35% | 7,160 |
| 超过 80,000 | 45% | 15,160 |

单独计税在临界点附近会出现「多发 1 元多缴上千元税」的区间（如 36,000 → 36,001）。发现奖金落在临界点上方附近时提醒用户，
并列出并入综合所得计税的对比，由用户决定，不要替用户选。

## 四、工资表的结构和核对

- 列的顺序建议：基本信息 → 应发各项 → 应发合计 → 个人社保公积金各项 → 专项附加扣除 → 累计各项 → 本月个税 → 其他扣款 → 实发。
- **实发 = 应发合计 − 个人社保公积金 − 本月个税 − 其他扣款**，逐行用公式，不手填。
- 核对：
  - 各部门小计之和 = 全公司合计；
  - 社保公积金个人部分 = 缴费基数 × 比例（基数先按上下限截取：`=MIN(MAX(工资,下限),上限)`）；
  - 本月个税合计与个税申报表（如用户提供）一致；
  - 实发合计与银行代发清单合计一致。
- 金额一律 `ROUND(...,2)`，比较用差额绝对值小于 0.005。

## 五、隐私

- 回复里说「第 12 行员工」而不是姓名 + 身份证号；汇总时说金额合计，不逐人念工资。
- 不要把工资明细复制到新的工作簿或别的表，除非用户要求。

## 常见报错

| 现象 | 常见原因 | 怎么办 |
|---|---|---|
| 某月个税突然变高 | 累计所得跨过税率档（正常）；或累计列断档 | 看累计应纳税所得额是否跨档，再查上月累计是否衔接 |
| 个税出现负数 | 没用 MAX(0, …) | 本月税额小于 0 时记 0，多缴的在年度汇算时退 |
| 社保和表上对不上 | 基数没截上下限、比例用错城市 | 查参数表 |
| 实发合计和代发清单差几分钱 | 各项没有 ROUND | 逐项 ROUND 到分 |
