# 销售报表

销售报表对不上，十有八九是**口径**不一致，不是公式错。动手前把口径问清楚，写进报表的说明里。

## 一、先确认口径

| 口径问题 | 常见选项 |
|---|---|
| 金额含不含税 | 含税价 ÷ (1 + 税率) = 不含税；增值税常见税率 13% / 9% / 6%，以用户业务为准 |
| 退货怎么算 | 负数行冲减当期；或单独一列「退货」；不要简单删掉负数行 |
| 按哪个日期归属 | 下单日、发货日、开票日、回款日——四个口径的月度数据都不一样 |
| 取消、作废订单 | 通常排除，看状态列 |
| 销量单位 | 件 / 箱 / 吨；不同单位不能直接相加 |

## 二、数据结构

- 分析前把数据整理成**明细长表**：一行一笔，列是日期、订单号、客户、产品、区域、数量、金额……
- 交叉表（每月一列）不适合做透视和筛选，先转成长表。
- 源数据转成「表格」（write_table），新加的行会自动进入透视表的数据源；透视表记得刷新（refresh_pivot）。

## 三、常用指标

| 指标 | 写法 | 注意 |
|---|---|---|
| 同比 | 本期 ÷ 上年同期 − 1 | 上期为 0 或负数时不计算，显示「—」并说明 |
| 环比 | 本期 ÷ 上期 − 1 | 月份天数不同，日均比较更公平时要说明 |
| 目标达成率 | 实际 ÷ 目标 | 目标为 0 或空时不计算 |
| 占比 | 本项 ÷ 合计 | 分母绝对引用；各项占比之和应为 100%（四舍五入有尾差） |
| 客单价 | 销售额 ÷ **订单数** | 订单数要按订单号去重计数，明细行数不是订单数 |
| 累计（YTD） | SUMIFS 日期 ≥ 年初 且 ≤ 截止日 | 截止日放参数单元格，不用 TODAY() |

按月汇总：`=SUMIFS(金额,日期,">="&月初,日期,"<"&EDATE(月初,1))`。透视表里按月看：group_pivot_date 按月 / 季度组合。

排名：`RANK.EQ` 有并列；Top N 用透视表的值筛选或 `LARGE`。

ABC 分析：按销售额降序，累计占比 ≤ 80% 为 A 类，80%–95% 为 B 类，其余 C 类（阈值可调，写在参数格里）。

## 四、图表选择

- 趋势（按月）：折线图；
- 构成：堆积柱形图；饼图只在类别 ≤ 6 个时用；
- 对比（区域、产品）：条形图 / 柱形图，按数值排序；
- 实际 vs 目标 + 达成率：组合图（柱形 + 折线次坐标轴，create_combo_chart）。
- 图表标题写清口径和单位：「2026 年 1–9 月各区域销售额（不含税，万元）」。

## 五、核对

- 报表总计 = 明细表总计（同一口径下）；各区域之和 = 全国合计；透视表总计 = 源数据 SUM。
- 同一个数在不同报表里出现时，数值一致。
- 汇报时写明：口径、数据截止日、排除了哪些数据（如作废订单多少笔、金额多少）。

## 常见报错

| 现象 | 常见原因 | 怎么办 |
|---|---|---|
| 透视表合计比明细少 | 数据源范围没包含新行；有文本型数字 | 源数据转成表格后刷新；查列类型 |
| 同比出现 #DIV/0! 或极大值 | 上年同期为 0 或很小 | 不计算，标注「新增」 |
| 客单价明显偏低 | 用明细行数当订单数 | 按订单号去重计数 |
| 各月加起来 ≠ 全年 | 日期口径不一，或有日期为空 / 文本的行 | 查日期列 |
