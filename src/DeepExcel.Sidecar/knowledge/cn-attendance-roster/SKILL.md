# 考勤与花名册

## 一、花名册

- **主键用工号，不用姓名**：同名很常见。工号、身份证号、银行卡号一律存成文本（被存成数字的，见 `cn-data-cleaning`）。
- 从身份证号取信息（18 位，A2 为文本）：
  - 出生日期：`=DATE(MID(A2,7,4),MID(A2,11,2),MID(A2,13,2))`
  - 性别：`=IF(MOD(MID(A2,17,1),2)=1,"男","女")`
  - 年龄（截至某日 D1）：`=DATEDIF(出生日期,$D$1,"y")`
  - 先用 `LEN(A2)=18` 过滤；15 位老号码、港澳台和外籍证件规则不同，单独列出来问用户。
- 工龄：`=DATEDIF(入职日期,截止日,"y")`；要精确到月用 `"ym"` 取零头月。截止日放一个单元格引用，不要用 `TODAY()`——
  文件每次打开结果都会变，月底存档的表过几天就对不上了。
- 在职 / 离职用状态列筛选，不要删离职员工的行：历史考勤和工资还要用。
- 花名册里是个人信息：回复里少复述身份证号、手机号。

## 二、打卡数据的常见形态

打卡机 / 办公软件导出的数据通常是：

1. **一行一次打卡**：工号、姓名、打卡时间（日期和时间在同一格，或者分两列）。
2. **一行一人一天**：上班打卡、下班打卡两列，缺卡为空或「未打卡」。
3. **交叉表**：一人一行，每天一列，格子里是「08:52 18:03」这样的文本。

先把它整理成「一行一人一天」：日期、工号、首次打卡、末次打卡。交叉表要先转成长表；格子里的多个时间用
split_text_to_columns 拆开。时间是文本的（「08:52」）用 `TIMEVALUE` 转，日期时间在一起的用 `INT` 取日期、`MOD(x,1)` 取时间。

## 三、迟到、早退、缺卡、工时

规定上班时间、下班时间、宽限分钟数都放参数单元格：

- 迟到：`=IF(首次打卡="","缺卡",IF(首次打卡>上班时间+宽限/1440,"迟到",""))`
- 迟到分钟：`=MAX(0,ROUND((首次打卡-上班时间)*1440,0))`
- 早退同理，比较末次打卡与下班时间。
- 工时（小时）：`=(末次-首次)*24`，扣午休时长。**跨午夜的夜班**：`=MOD(末次-首次,1)*24`。
- 只有一次打卡的，首次 = 末次，不能算出 0 工时就当正常：单独标「缺卡」。

## 四、工作日、法定节假日和调休

- 法定节假日和调休上班日**每年由国务院办公厅公布**，不能写死，也不能只看周六日。
  建一张「日历」参数表：日期、类型（工作日 / 休息日 / 法定节假日）。没有这张表时，请用户提供当年的放假安排。
- `NETWORKDAYS.INTL(开始,结束,1,节假日列表)` 能排除周末和节假日，但**处理不了周末调休上班**：按日历表的类型统计更可靠：
  `=COUNTIFS(日历!A:A,">="&开始,日历!A:A,"<="&结束,日历!B:B,"工作日")`
- 加班按日期类型区分：工作日延时、休息日、法定节假日（法定标准分别不低于 150%、200%、300%，休息日可安排补休）。
  公司制度不同的按公司制度，参数放参数表。
- 日工资常用 月工资 ÷ 21.75（月计薪天数）；公司另有规定的按规定。

## 五、核对

- 每人每月的出勤天数 + 请假天数 + 缺勤天数 = 应出勤天数（日历表里的工作日数）。
- 汇总表的人数 = 花名册里该月在职人数；多出来的人（离职后还有打卡）、少了的人（新入职没录入）列出来。
- 同一人同一天有多条记录：取最早和最晚，不要重复计算。

## 常见报错

| 现象 | 常见原因 | 怎么办 |
|---|---|---|
| 时间比较全部判成迟到 | 打卡时间是文本 | TIMEVALUE 转换后再比较 |
| 工时出现负数 | 跨午夜 | 用 MOD(末次-首次,1) |
| 出勤天数多算 | 调休上班日没算进工作日，或节假日没排除 | 用日历表统计 |
| DATEDIF 返回 #NUM! | 开始日期晚于结束日期（入职日期填错） | 列出这些行请用户核对 |
