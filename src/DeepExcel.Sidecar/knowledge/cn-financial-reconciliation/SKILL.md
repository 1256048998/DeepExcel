# 财务报表勾稽核对（中国企业会计准则口径）

勾稽核对的目的是找出对不上的地方并说明原因，**不是把数字改到对得上**。
发现差异时，报告差异金额、涉及的项目和可能原因，由用户决定怎么处理。绝对不要为了平衡而倒挤数字。

## 开始之前

1. 确认报表口径：一般企业（《企业会计准则》，财会〔2019〕6 号及之后的报表格式）还是小企业（《小企业会计准则》）；
   单体还是合并。
2. 确认单位：元 / 千元 / 万元；各张表单位是否一致。
3. 确认期间：本期、上期（上年同期）、期初、期末分别在哪一列。
4. 确认容差：通常以四舍五入误差为限（元为单位时 ±1 元以内，万元为单位时 ±0.01 万）。超过容差的都要报告。

## 一、资产负债表内部

- **资产总计 = 负债合计 + 所有者权益（或股东权益）合计**，期末、期初两列分别核。
- 各小计 = 所属明细之和：流动资产合计、非流动资产合计、流动负债合计、非流动负债合计、所有者权益合计。
- 合并报表：所有者权益合计 = 归属于母公司所有者权益合计 + 少数股东权益。
- 本期期初数 = 上期期末数。不一致时，看是否有会计政策变更、前期差错更正（报表上会有「调整」或「重述」说明），
  没有说明的不一致要报告。

## 二、利润表内部

按报表格式的计算链逐级核：

- 营业利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用
  + 其他收益 + 投资收益 + 净敞口套期收益 + 公允价值变动收益 + 信用减值损失 + 资产减值损失 + 资产处置收益
  （各项损失、减值以负数列示时是「加」，以正数列示时是「减」——先看这张表的列示习惯）
- 利润总额 = 营业利润 + 营业外收入 − 营业外支出
- 净利润 = 利润总额 − 所得税费用
- 合并报表：净利润 = 归属于母公司股东的净利润 + 少数股东损益
- 综合收益总额 = 净利润 + 其他综合收益的税后净额
- 「其中」项（如财务费用中的利息费用、利息收入）不参与加总，只核不超过所属项目。

## 三、现金流量表内部

- 经营 / 投资 / 筹资活动各自：现金流量净额 = 现金流入小计 − 现金流出小计。
- 现金及现金等价物净增加额 = 经营活动净额 + 投资活动净额 + 筹资活动净额 + 汇率变动对现金的影响。
- 期末现金及现金等价物余额 = 期初余额 + 净增加额。
- 补充资料（间接法）：将净利润调节为经营活动现金流量，结果应当等于主表的经营活动现金流量净额。

## 四、表与表之间

| 核对 | 关系 | 对不上的常见原因 |
|---|---|---|
| 现金流量表期末现金 vs 资产负债表货币资金 | 通常 货币资金 ≥ 现金及现金等价物，差额是受限资金（保证金、冻结存款）或三个月以上定期存款 | 差额要能在附注里找到解释 |
| 利润表净利润 vs 未分配利润变动 | 期末未分配利润 = 期初 + 归母净利润 − 提取盈余公积 − 分配股利 ± 其他 | 有分红、提取公积、政策变更调整期初 |
| 所有者权益变动表 vs 资产负债表 | 权益变动表各列期末数 = 资产负债表对应权益项目期末数 | 合并口径和单体口径混用 |
| 现金流量表补充资料 vs 资产负债表 | 存货减少、经营性应收减少、经营性应付增加 ≈ 资产负债表期初期末差额 | 合并范围变化、非现金交易、重分类，不要求严格相等 |
| 利润表 vs 科目余额表 | 损益类科目本期发生额 = 利润表对应项目 | 科目和报表项目的映射关系 |

## 五、科目余额表

- **期初借方合计 = 期初贷方合计；本期借方发生额合计 = 本期贷方发生额合计；期末借方合计 = 期末贷方合计。**
- 单个科目期末余额：
  - 借方余额科目（资产、成本、费用）：期末 = 期初 + 本期借方 − 本期贷方
  - 贷方余额科目（负债、所有者权益、收入）：期末 = 期初 + 本期贷方 − 本期借方
- 损益类科目结转后期末余额应为 0；不为 0 说明没结转或结转不完整。
- 一级科目余额 = 所属明细科目余额之和。
- 报表项目不是科目的简单照搬：应收账款按净额列示（减坏账准备），「其他应收款」含应收利息和应收股利，
  「应付账款」借方余额要重分类到预付款项——按科目直接加总核报表时会有差异，要说明是重分类还是真差异。

## 六、怎么交付

1. 另建一张「勾稽核对」工作表，不要改原报表。
2. 每条核对一行：核对项目、左边的值（用公式引用原表单元格）、右边的值（公式引用）、差额（公式）、
   是否通过（`=IF(ABS(差额)<=容差,"通过","差异")`）、说明。
3. **全部用公式引用原表**，不要把数值抄过来：用户改了报表，核对结果要跟着变。
4. 汇报时先说通过了几条、有差异的几条，差异逐条说金额和可能原因。

## 七、小企业会计准则的差异

- 报表格式更简单：没有「其他综合收益」、没有「信用减值损失」，研发费用可能并在管理费用里。
- 投资类项目简单（短期投资、长期债券投资、长期股权投资），长期股权投资用成本法，没有公允价值变动损益。
- 核对时先确认用的是哪套准则，不要用一般企业的项目清单去要求小企业报表。

## 常见报错

| 现象 | 常见原因 | 怎么办 |
|---|---|---|
| 资产 ≠ 负债 + 权益，差额很小 | 四舍五入（报表以万元列示，明细以元计算） | 在容差内的标注「尾差」 |
| 差额正好是某一项的两倍 | 这一项的符号用反了（损失按正数列示却做了加法） | 看列示习惯，调整核对公式，不调整报表 |
| 现金流量表期末现金 ≠ 货币资金 | 受限资金、定期存款 | 找附注说明，差额列出来 |
| 本期期初 ≠ 上期期末 | 重述、政策变更，或者上期报表用错版本 | 问用户有没有调整说明 |
| 核对公式全是 #REF! | 引用的报表工作表被改名或删除 | 重新定位原表 |
